# التقويم العائلي 📅

تطبيق عربي لتنظيم التقويم العائلي والمواعيد والأحداث المشتركة بين أفراد العائلة، مع دعم التاريخ الهجري وإدارة المشاركة والصلاحيات.

## 🌐 تشغيل البرنامج

▶️ [فتح برنامج التقويم العائلي](https://adelss12.github.io/fc/)

يعمل البرنامج مباشرة من المتصفح، ويمكن استخدامه على الكمبيوتر أو إضافته إلى الشاشة الرئيسية في الآيفون للوصول إليه بسرعة.

## ✨ المميزات

- تنظيم المواعيد والأحداث العائلية.
- مشاركة الأحداث بين أفراد العائلة.
- دعم التاريخ الهجري.
- إدارة المستخدمين والصلاحيات.
- إمكانية قبول أو رفض المشاركات.
- واجهة عربية مناسبة للجوال والكمبيوتر.
- مزامنة البيانات بين الأجهزة.
- يعمل مباشرة من المتصفح.
